# App Store Optimization (ASO) & Competitor Analysis

## Primary keywords (intent → term)
| Intent | Keyword | Priority |
|--------|---------|----------|
| Core | morse code | High |
| Core | morse translator | High |
| Core | morse code translator | High |
| Feature | morse decoder | High |
| Feature | text to morse | Medium |
| Feature | morse to text | Medium |
| Feature | flashlight morse | Medium |
| Feature | morse code generator | Medium |
| Audience | ham radio / amateur radio | Medium |
| Audience | learn morse code / morse trainer | Medium |
| Brand/other | cw, sos signal, morse beep | Low–Medium |

## Keyword placement strategy
- **Title (30 chars):** "Morse Translator Pro" — includes the two highest-value
  terms ("Morse", "Translator").
- **Short description (80 chars):** front-load "Morse code" + the three verbs
  (translate, flash, beep, decode) + "offline" differentiator.
- **Full description:** naturally repeat "Morse code", "decoder", "translator"
  3–5 times; cover long-tail ("text to morse", "flashlight morse", "ham radio").
- Avoid keyword stuffing (Play penalizes it); write for humans first.

## Differentiators to emphasize vs. competitors
1. **All four I/O modes** (flashlight + audio + vibration transmit; camera +
   mic decode) in one app.
2. **Fully offline** and **no ads / no tracking** — privacy-first.
3. **Modern Material You UI** (many competitors look dated).
4. **Confidence scoring** on live decoding.
5. **Accessibility**: dark mode, large text, haptics, screen-reader labels.

## Competitor analysis
| App | Strengths | Gaps we exploit |
|-----|-----------|-----------------|
| Morse Code Translator (various) | Simple, popular, good keyword rank | Often ad-heavy, dated UI, limited decoding |
| Morse Mania | Great for *learning* CW, gamified | Not a general translator/transmitter/decoder |
| Morse Code Agent | Decent decoder | Fewer transmit modes; UI less modern |
| Morse Expert | Audio decode focus | No camera decode; weaker sharing/history |

**Positioning:** "The all-in-one, modern, private Morse toolkit — translate,
transmit *and* decode, offline." Learning apps (Morse Mania) and we are
complementary, not direct competitors; target general + utility users.

## Conversion assets
- Icon: bold `. — .` glyph on blue — high contrast, readable at small sizes.
- First 2 screenshots must show (1) Text→Morse result and (2) a decoder with a
  live confidence score — the clearest value props.
- Feature graphic tagline: "Translate · Transmit · Decode — Offline".

## Review & rating strategy
- Prompt for a rating after a *successful* decode or a few saved translations
  (positive moment), never on first launch.
- Respond to all reviews; turn 1–3★ feedback into roadmap items.

## Localization (phase 2)
Prioritize: Spanish, Portuguese (BR), German, French, Russian, Hindi,
Indonesian — large ham-radio / hobbyist communities and high Android share.

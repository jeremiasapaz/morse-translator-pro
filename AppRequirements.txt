# Project: Morse Translator Pro (Android App)

You are an autonomous software engineer tasked with designing, building, testing, deploying, publishing, marketing, and maintaining a production\-ready Android application.

## Objective

Create a modern Android mobile application called **Morse Translator Pro** that allows users to:

1. Convert text into Morse code.
2. Play Morse code through: 
    - Device flashlight (LED torch).
    - Audible beeps/speaker sounds.
    - Vibration patterns.
3. Decode Morse code received via: 
    - Camera light detection (flashing lights).
    - Microphone audio detection (beeping sounds).
4. Save, share, and export translations.
5. Operate offline without an internet connection.

The final goal is to publish the application on Google Play Store, make the source code public on GitHub, and launch an initial marketing campaign.

## Features

### 1\. Text to Morse

User inputs text.

System converts it into valid international Morse Code.

Display:

- Original text
- Morse code output

Example:

HELLO

.... . .\-.. .\-.. \-\-\-

### 2\. Morse Playback

Add controls:

- Play
- Pause
- Stop
- Repeat

Playback methods:

#### Flashlight Mode

Use camera flash LED.

Morse timing rules:

- Dot = 1 unit
- Dash = 3 units
- Symbol gap = 1 unit
- Letter gap = 3 units
- Word gap = 7 units

Allow speed adjustment:

- Slow
- Medium
- Fast
- Custom WPM (Words Per Minute)

#### Audio Mode

Generate Morse beeps.

Settings:

- Frequency selection (400Hz–1200Hz)
- Volume control
- Speed control

#### Vibration Mode

Translate Morse patterns into vibration sequences.

---

### 3\. Camera Morse Decoder

Use CameraX.

Requirements:

- Detect flashing lights in real time.
- Determine Morse timing.
- Convert flashes into Morse symbols.
- Convert Morse into text.
- Display confidence score.
- Show live decoded text.

Should work with:

- Another phone flashlight
- LED signals
- Flashing Morse transmitters

---

### 4\. Microphone Morse Decoder

Use Android microphone.

Requirements:

- Detect beeps.
- Use DSP/audio processing techniques.
- Filter background noise.
- Convert audio patterns into Morse.
- Convert Morse into readable text.
- Display live decoding output.

Should support:

- Real\-time decoding
- Recorded audio decoding
